🎓 MD5 Explained — A Brilliant Tool That Time Broke

What MD5 is. Designed in 1992 by Ron Rivest, MD5 turns any input into a 128-bit fingerprint written as 32 hex characters. It was fast, simple, and became the internet's default checksum for downloads, file verification and (mistakenly) password storage.
What "broken" means. A secure hash must make it practically impossible to find two different inputs with the same hash (a "collision"). Researchers demonstrated MD5 collisions in 2004, and by 2008 attackers forged a real web certificate with one. Collisions are now cheap to produce on a home computer.
Why passwords + MD5 = disaster. MD5 is FAST — billions of guesses per second on a GPU. A leaked database of MD5 password hashes falls to brute force almost immediately. Password storage needs slow, salted algorithms: bcrypt, scrypt or Argon2.
Where MD5 is still fine. Non-adversarial jobs: detecting accidental corruption (a flipped bit during transfer), deduplication, cache keys, checksums inside rsync/Git-style tooling for non-security purposes, and matching legacy fingerprints where nobody is trying to deceive you.
